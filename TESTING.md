# Webizon — Чек-лист ручного тестирования

> Роли: **O** = TENANT_OWNER, **A** = TENANT_ADMIN, **M** = TENANT_MODERATOR, **P** = TENANT_PRESENTER, **AN** = TENANT_ANALYST, **U** = Публичный пользователь (авторизованный)

## 1. Аутентификация (все роли)

- [ ] Неавторизованный пользователь открывает `/admin` → редирект на страницу входа Keycloak
- [ ] Неавторизованный пользователь открывает `/e/{tenant}/{slug}` → лендинг виден, участие требует авторизации
- [ ] После входа пользователь перенаправляется обратно на исходную страницу
- [ ] Dev-режим (`npm run dev`) → авторизация автоматически установлена через плагин `auth.client.ts`, без редиректа на Keycloak
- [ ] В auth store корректные значения: `tenantSlug`, `tenantId`, `role`, `fullName`

## 22. Режимы чата (O, A, P — настройка в админке; U — действует в комнате)

- [ ] Режим **EVERYONE**: все авторизованные пользователи могут писать сообщения
- [ ] Режим **ADMINS_ONLY**: только модераторы/админы/презентеры могут писать; остальные видят бейдж «Только чтение»
- [ ] Режим **DISABLED**: никто не может писать; чат показывает сообщение об отключении
- [ ] Смена режима в админке → комната сразу отражает изменения (после обновления bootstrap)
- [ ] Capabilities `canSendChat` / `canReplyInChat` корректно ограничены режимом + ролью

## 24. Модерация / Цепочка политик (бэкенд)

- [ ] **BanPolicy**: забаненный пользователь не может отправлять сообщения → ответ с ошибкой
- [ ] **MutePolicy**: замученный пользователь не может писать до истечения мута → ошибка с оставшимся временем
- [ ] **SlowModePolicy**: пользователь пишет слишком часто → ошибка с временем ожидания; админы обходят ограничение
- [ ] **LinkPolicy**: сообщение с URL отклоняется при `allowLinks=false` → ошибка
- [ ] **WordFilterPolicy**: сообщение с нецензурной лексикой отклоняется при включённом фильтре → ошибка
- [ ] **FloodProtectionPolicy**: повторяющиеся идентичные сообщения отклоняются → ошибка
- [ ] Все действия модерации логируются в таблице `moderation_actions`
- [ ] Действия модерации видны в аналитике/обзоре админ-панели

## Настройка окружения для тестирования

```bash
# Запуск всех сервисов
cd E:\PROJECT\webizon
docker-compose up -d

# Проверка здоровья сервисов
docker-compose ps

# Frontend: http://localhost:3000
# Backend: http://localhost:8080
# Keycloak: http://localhost:8180
# MinIO Console: http://localhost:9001
# Centrifugo: http://localhost:8001

# Dev-режим (Docker не нужен для фронтенда):
cd frontend
npm run dev
# Авторизация автоматическая: dev-user с ролью TENANT_OWNER
```

---

## Примечания

- В dev-режиме авторизация замокана — тесты с ролевым доступом следует также проверять в Docker-режиме с реальными JWT-токенами Keycloak
- Тесты чата в реальном времени требуют работающего Centrifugo
- Тесты аналитики требуют сессию, которая была в статусе LIVE, затем ENDED, с отслеженными событиями
- Тесты цепочки политик требуют отправки запросов напрямую к API бэкенда или через чат комнаты
